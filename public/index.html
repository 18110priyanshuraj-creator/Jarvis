Live research privacy and cost

Live mode is disabled by default; availability depends on server settings. When enabled, your question is sent to Google Gemini with Google Search grounding. Results show source links and are not saved automatically; use “Save research” to keep one in your private JARVIS history. Google’s Search grounding has a free monthly allowance and may incur usage charges after that. Do not enable paid billing without a parent or guardian reviewing it.

CONNECTED SERVICES

Connections

Connect read-only services to JARVIS workflows. You control which server credentials are configured.

Credential privacy

API tokens are read only from your server environment variables. This page never asks you to paste a secret and JARVIS does not save credentials in its database, workflow definitions, run logs or browser storage. All supported operations are read-only.

To connect a service, add its environment variable in your hosting provider's server-side environment settings, then restart or redeploy the server.

Supported server variables
  • JARVIS_GITHUB_TOKEN — read-only GitHub profile and repository access
  • JARVIS_GOOGLE_DRIVE_ACCESS_TOKEN — Google Drive file metadata read access
  • JARVIS_TELEGRAM_BOT_TOKEN — Telegram bot profile check only; no message sending
  • JARVIS_ELEVENLABS_API_KEY — ElevenLabs account summary only

Google Drive access tokens expire. Refresh-token OAuth and automatic token refresh are not included in this phase.
