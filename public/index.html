      CONNECTED SERVICES

      Connections

      Connect read-only services to JARVIS workflows. You control which server credentials are configured.

      Credential privacy

      GitHub, Telegram and ElevenLabs credentials are read only from server environment variables. Google Drive refresh tokens are encrypted with AES-256-GCM before being saved; access tokens stay in server memory. Secrets are never entered in the browser or included in workflow logs and data exports.

      Connect Google Drive with the button below. JARVIS requests only read-only Drive metadata permission and refreshes access tokens on the server. Keep the encryption key and OAuth client secret in your hosting provider's private environment settings.

      Important: Google revocation removes OAuth scopes previously granted to the same Google Cloud project and can invalidate tokens for other clients registered in that project. Use a dedicated Google Cloud project for JARVIS if you need isolation.

      Supported server variables
      • JARVIS_GOOGLE_OAUTH_CLIENT_ID and JARVIS_GOOGLE_OAUTH_CLIENT_SECRET — server-side OAuth client
      • JARVIS_GOOGLE_OAUTH_REDIRECT_URI — exact HTTPS callback URL ending in /api/integrations/google_drive/oauth/callback
      • JARVIS_TOKEN_ENCRYPTION_KEY — 32-byte key used to encrypt stored OAuth refresh tokens
      • JARVIS_GITHUB_TOKEN — optional fine-grained token with Metadata: read, or a GitHub App installation
      • JARVIS_TELEGRAM_BOT_TOKEN — bot identity check only; no message sending
      • JARVIS_ELEVENLABS_API_KEY — restricted API key for account summary only
      • JARVIS_GOOGLE_DRIVE_ACCESS_TOKEN — optional legacy short-lived token fallback

      Generate the 32-byte encryption key on your own device and save it privately. Never commit it or paste it into chat. The same key must remain available to decrypt the saved connection after a restart.
