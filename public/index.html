JARVIS PERSONAL ASSISTANT

What are we working on?

Use the built-in offline brain by default. Optional Gemini conversation can be enabled in server settings for more open-ended replies.

Privacy: Gemini chat is opt-in. When enabled, up to 8 recent user/assistant messages (max 1,200 characters each) may be sent to Gemini. Saved memories, tasks, screenshots and Android screen text are not included. Separately, if the server has a Gemini API key, paired Android voice transcripts are sent to Gemini for request routing.

JARVIS can make mistakes. Verify important information. External actions are not enabled.
