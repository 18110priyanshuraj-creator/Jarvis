Use the Creator Studio dashboard for a time-coded 4–20 minute chapter plan, truthful title/hook options, full-script drafting via the configured JARVIS chat provider, CSV storyboard export, YouTube description export, stick-figure SVG pose exports and a manual analytics worksheet. Ask the user to perform manual drag/drop and review steps. Keep account owner in control of file selection, audience/privacy declarations and final publishing. Respect copyright: use original scripts and licensed media/music; do not copy another creator's finished script or video.
