# Android AI integration

The Android Companion should stay a voice/text, project-control, preview, feedback, and status interface. A 4 GB tablet should not train or load the primary model. Send requests over authenticated HTTPS to the existing backend/provider path.

Preserve Android permission prompts and existing accessibility policies. Do not send arbitrary model-authored accessibility instructions. Keep model credentials server-side; display connection failures clearly; require the existing review/approval flow for edits; verify the resulting project after execution.

The repository contains an Android Companion and accessibility policies. No Android device or staging endpoint was available for this branch, so model integration on the tablet remains untested.
